# Anästhesie Kompass

Private, nicht kommerzielle Lernhilfe zur Vorbereitung auf die Facharztprüfung Anästhesiologie.
**Kein Medizinprodukt – nicht zur Anwendung bei Patientinnen und Patienten bestimmt.**

## Veröffentlichen mit GitHub Pages

1. In `index.html` ganz oben im Skript den Block `SITE.impressum` ausfüllen (Name, ladungsfähige Anschrift, E-Mail).
2. Neues Repository anlegen und `index.html` (und diese README) hochladen.
3. *Settings → Pages → Source: Deploy from a branch → main / root*.
4. Nach 1–2 Minuten ist die Seite unter `https://<benutzername>.github.io/<repository>/` erreichbar.

## Vor der Veröffentlichung prüfen

- [ ] Impressum ausgefüllt (bei einer öffentlich zugänglichen Fachseite der sichere Weg)
- [ ] Keine Inhalte aus Klinik-SOPs, keine Patientendaten, keine Fotos/Abbildungen aus Büchern
- [ ] Keine Werbung, keine Spenden- oder Bezahl-Links (sonst ändert sich die rechtliche Lage)
- [ ] Hinweisfenster und Seite „Rechtliches“ unverändert gelassen
- [ ] Bei Änderungen der Inhalte `SITE.stand` aktualisieren

## Technik

Eine einzige HTML-Datei ohne externe Abhängigkeiten: keine externen Schriftarten, kein Tracking, keine Cookies.
Lernfortschritt wird nur im localStorage des Browsers gespeichert.
